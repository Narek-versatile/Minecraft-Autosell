# What autosell-debug.log looks like, and how to read it
#
# The single most useful artifact for remote debugging. Ask the user for it
# before theorising about any reported symptom - it resolved several bugs on
# first read where description alone had gone in circles.
#
# Every phase change logs a one-line state dump:
#   cycle       fuel cycle index
#   step        index into the recorded shop path
#   target      stacks the run intends to buy
#   qtySlot     slot holding the amount counter
#   awaiting    counter value being waited for (-1 = not waiting)
#   resume      resume crafting after the current drop
#   resultWait  ticks spent waiting for the server's crafting result
#   fails       consecutive craft failures
#   bones/meal  live inventory counts
#   carried     what is on the cursor ("-" = empty)
#   screen      open screen title ("-" = none)
#   walker      baritone | builtin | align | off
#
